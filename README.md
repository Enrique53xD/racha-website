# racha-website

Sitio estático de Racha (landing + soporte). Sin build step — HTML/CSS plano, listo para desplegar
en Vercel tal cual.

## Estructura

- `index.html` — landing (`/`)
- `soporte/index.html` — página de soporte (`/soporte`)
- `styles.css` — estilos compartidos

## Deploy

Importar el repo directo en Vercel (framework preset: "Other" / estático) — no requiere comando de
build ni output directory.
